# SETTINGS
settings are at "Appdata\Local\Kazii\Archipelago Speedrun Splitter" on windows or "~/.config/Archipelago Speedrun Splitter" on linux a way to change these from the application will be done in the future. 

server: the archipelago server you want to connect to( ie localhost, archipelago.gg)
port: the port number you want to connect to
password: the password of the server if any
username: the slot name of your user
speedrunType: the type of timer you want to connect to. OSR for openspeedrun LiveSplit for livesplit
openSpeedrunSocket: the path to the open speedrun socket
livesplitHost: the host of the livesplit program
livesplitPort: the port of the livesplit program
